# Metodologia

1. O programa lê uma linha de cabeçalho e ignora-a.
2. Cada linha seguinte representa um período mensal.
3. O volume de gás é convertido de milhões de m³/d para boe/d com o fator ilustrativo de 6,2898 barris por m³.
4. O total equivalente estimado é a soma do petróleo em bbl/d com o gás convertido em boe/d.
5. O programa apresenta os dados por período e um resumo das taxas diárias registradas.

## Interpretação correta
Somar taxas diárias de meses diferentes não produz um total anual significativo. Para análises temporais, compare cada período individualmente ou calcule médias e volumes totais usando o número de dias de cada mês. O programa demonstra leitura e cálculo básicos; não é um sistema contábil ou de reporte regulatório.

## Dados
Os registros incluídos são exemplos ilustrativos. Para uso analítico, obtenha os dados mais recentes da ANP, registre a data de extração, preserve a unidade original e valide o fator de conversão aplicável.
